## 工夫したこと
メニューのページは将来、犬種が増えていく事を考慮して犬種＝投稿タイトルにしています。
また、価格が変化することを考慮して金額の欄にカスタムフィールドを使用しました。  
掲載画像は『O-DAN』、人物画像は『いらすとや』で提供されている素材を使用し、画像容量の大きいものは表示の高速化を考慮してWebP形式へ変換しています。
